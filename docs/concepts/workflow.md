**Бизнес-процесс** - это, по сути, совокупность [действий](./action.md) и [статусов](./status.md), 
которые применимы к определенному классу сущностей.

Объект бизнес-процесса, таким образом, это просто коллекция [действий](./action.md) и [статусов](./status.md)
с некоторыми дополнительными особенностями.

# Классы и интерфейсы

## #[AsWorkflow]

Атрибут <code><b>SprintF\Bundle\Wolfflow\Attribute\AsWorkflow</b></code>, которым обязательно должен быть помечен 
класс процесса. Имеет следующие свойства:
- <code>string <b>$workflow</b></code> Символьное имя бизнес-процесса

## WorkflowInterface

Интерфейс <code><b>SprintF\Bundle\Wolfflow\Workflow\WorkflowInterface</b></code> устанавливает общие требования ко всем
классам всех бизнес-процессов, а именно определяет следующие методы:

- <code><b>getName()</b>: string</code> Метод, возвращающий символьное имя данного бизнес-процесса.
- <code><b>setActions(</b>ActionCollection $actions<b>)</b></code> Метод для передачи коллекции всех действий. 
Используется на этапе компиляции.
- <code><b>getActions()</b>: array</code> Метод получения всех [действий](./action.md) данного процесса.

## WorkflowAbstract

Типовой абстрактный базовый класс <code><b>SprintF\Bundle\Wolfflow\Workflow\WorkflowAbstract</b></code> для бизнес-процессов,
включенный в состав бандла для удобства применения в приложениях. Класс реализует:

- Стандартный способ определения символьного имени бизнес-процесса, исходя из атрибута `#[AsWorkflow]`
- Инъекцию списка всех действий данного бизнес-процесса (на этапе компиляции)
- Методы `getName()` и `getActions()` 

Свои классы бизнес-процессов в приложении можно наследовать от данного абстрактного класса.
