<b>Контекст</b> - это данные, необходимые для выполнения того или иного [действия](./action.md).

Общепринято для каждого действия определять свой дата-класс контекста. Лучше всего это делать, используя 
стандартные средства бандла.

# Классы и интерфейсы

## ContextInterface
Интерфейс <code><b>SprintF\Bundle\Wolfflow\Context\ContextInterface</b></code> задаёт лишь одно требование 
для всех дата-классов контекста действий: иметь возможность корректной сериализации в JSON. 
С этой целью данный интерфейс наследуется от интерфейса `\JsonSerializable`.

## ContextAbstract

Абстрактный класс  <code><b>SprintF\Bundle\Wolfflow\Context\ContextAbstract</b></code>, реализующий интерфейс 
`ContextInterface`. Реализация содержит всего один метод: `jsonSerialize(): array`, который возвращает 
массив из свойств объекта и их значений.

В процессе такой нормализации идет поиск атрибута `#[\SensitiveParameter]` у свойств, определенных в конструкторе класса. 
Если данный атрибут имеется - значение свойства заменяется на "●●●".

Классы контекста действий в приложении рекомендуется наследовать от данного класса.
